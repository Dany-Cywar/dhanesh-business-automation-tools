# StatementIQ — Bank & Credit Card Statement Analyser

Browser-only statement analysis tool for extracting, reviewing and analysing bank and credit-card statement data.

## Highlights
- Processes bank and credit-card statement files in the browser
- Uses PDF parsing and OCR for statement extraction
- Provides transaction analysis, summaries and visual dashboards
- Supports Excel-oriented processing and export workflows
- Designed with privacy-focused local processing

## Technology
HTML, CSS, JavaScript, PDF.js, Tesseract.js, SheetJS, ExcelJS and Chart.js

## Run locally
Open `index.html` in a modern web browser.
