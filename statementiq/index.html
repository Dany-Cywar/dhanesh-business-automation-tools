How to use StatementIQ

  1. Upload. Drop in bank and credit card statements together — PDF, XLSX or CSV. Password-protected PDFs prompt for the password; nothing is stored.
  2. Verify columns. Check the detected column roles and fix any that are wrong with the dropdowns.
  3. Review. Edit any cell that came through wrong. Problem rows are flagged, never dropped.
  4. Analyse. Switch to the Bank or Credit card tab. Recategorise anything — the merchant rule is remembered on this browser.
  5. Reconcile. Card-to-bank runs on what is already loaded. Book-to-bank needs your own sheet.
  6. Export. Press Ctrl+E for the multi-sheet workbook.
The Excel writer cannot create native Excel charts from the browser. Monthly Trend and Category Summary are laid out as clean contiguous blocks, so you can select the range and press Alt+F1 to get a chart in two clicks.

Passwords on Indian statements

Common formats, in the order worth trying:

  • PAN in lowercase + date of birth as DDMM — abcde1234f0107
  • First four letters of your name + date of birth as DDMM
  • Date of birth as DDMMYYYY
  • Customer ID or account number
  • Last four digits of the card + date of birth as DDMM (credit cards)
  • Mobile number, or the first four letters of the card name in caps + last four card digits (Amex)

This tool extracts and analyses data from statements you provide. Always verify the extracted figures against your original statement before using them for tax filing, loan applications, or any financial decision. This is not financial or tax advice.
