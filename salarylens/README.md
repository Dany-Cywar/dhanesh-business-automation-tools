# SalaryLens — CTC Decoder & Offer Comparator

Salary and compensation analysis tool for decoding CTC structures, estimating in-hand pay and comparing job offers.

## Highlights
- Breaks down compensation and CTC components
- Estimates take-home / in-hand salary
- Compares multiple compensation offers
- Presents deductions, savings and comparison insights
- Includes responsive design and dark-mode support

## Technology
HTML, CSS and JavaScript

## Run locally
Open `index.html` in a modern web browser.
