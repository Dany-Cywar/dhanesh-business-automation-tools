# PDF Toolkit

Browser-based PDF merge, split, extract, reorder and page-organization utility.

## Highlights
- Merge and split PDFs
- Extract, rotate, duplicate and delete pages
- Reorder pages visually
- Processes files locally in the browser

## Technology
HTML, CSS, JavaScript, PDF.js, pdf-lib and JSZip

## Run locally
Open `index.html` in a modern browser.
