# Minutes Maker

Offline meeting-minutes tool that converts raw notes into structured minutes, decisions, owners and deadlines.

## Highlights
- Turns raw transcripts or notes into structured minutes
- Surfaces decisions, owners and deadlines
- Supports export/copy workflows
- Runs locally in the browser

## Technology
HTML, CSS and JavaScript

## Run locally
Open `index.html` in a modern browser.
