# MoneyDesk — Personal Finance Workbench

Personal finance workbench for budgeting, transaction tracking, savings analysis and financial dashboards.

## Highlights
- Provides KPI-style views of personal finances
- Supports budgeting, transaction and category-based analysis
- Uses charts and tabular views for financial reporting
- Includes responsive layouts and dark-mode support

## Technology
HTML, CSS, JavaScript and Chart.js

## Run locally
Open `index.html` in a modern web browser.
