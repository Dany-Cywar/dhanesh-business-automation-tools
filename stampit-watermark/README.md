# StampIt

Bulk PDF/image watermarking tool with text/logo modes, live preview and configurable placement.

## Highlights
- Bulk watermark PDFs and images
- Text, logo and combined watermark modes
- Live preview and reusable settings
- Local browser processing

## Technology
HTML, CSS, JavaScript, pdf-lib, PDF.js and JSZip

## Run locally
Open `index.html` in a modern browser.
