# MatchPoint — Resume vs JD Analyser

Privacy-focused browser tool that compares a resume with a job description, scores alignment and surfaces matched, partial and missing keywords.

## Highlights
- Accepts PDF, DOCX and TXT resumes
- Calculates resume-to-job-description match scores
- Highlights matched, partial and missing keywords
- Provides ATS-style checks, recommendations and rewrite guidance
- Runs document analysis locally in the browser

## Technology
HTML, CSS, JavaScript, PDF.js and Mammoth.js

## Run locally
Open `index.html` in a modern web browser.
