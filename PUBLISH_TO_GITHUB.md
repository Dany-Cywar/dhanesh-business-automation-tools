# Upload / Update this portfolio on GitHub

Repository:
`https://github.com/Dany-Cywar/dhanesh-business-automation-tools`

## If the repository already exists

1. Open the repository in GitHub.
2. Click **Add file** → **Upload files**.
3. Open this extracted folder on your computer.
4. Drag the new project folders into the GitHub upload area:
   - `net-worth-calculator`
   - `gst-invoice-generator`
   - `matchpoint-resume-jd-analyser`
   - `moneydesk`
   - `statementiq`
   - `salarylens`
5. Also upload the updated top-level `README.md`.
6. In the commit message box, enter:
   `Add six new business automation projects`
7. Click **Commit changes**.

If the repository is still empty, upload all project folders and the top-level files together.
