# InstantDash

Excel/CSV dashboard builder with KPIs, filters, charts, pivot analysis and data-quality review.

## Highlights
- Reads Excel/CSV files in the browser
- Builds KPI cards and interactive charts
- Supports pivot/cross-tab analysis and data-quality review
- Keeps working data local in the browser

## Technology
HTML, CSS, JavaScript, SheetJS and Chart.js

## Run locally
Open `index.html` in a modern browser.
