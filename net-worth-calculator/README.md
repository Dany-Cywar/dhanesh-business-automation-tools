# Net Worth Calculator

Personal net-worth tracker for assets, liabilities, category breakdowns, financial KPIs, history and trend analysis.

## Highlights
- Tracks assets and liabilities by customizable categories
- Calculates total net worth and asset/liability mix
- Includes analysis KPIs, history tracking and trend visualization
- Designed as a browser-based personal finance tool

## Technology
HTML, CSS and JavaScript

## Run locally
Open `index.html` in a modern web browser.
