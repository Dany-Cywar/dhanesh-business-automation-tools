# GST Invoice Generator

Browser-based Indian GST invoice builder with tax calculations, invoice preview, history and PDF export.

## Highlights
- Creates GST-ready invoices with seller, buyer and line-item details
- Handles taxable values, discounts and GST calculations
- Shows intra-state/inter-state supply treatment and invoice totals
- Exports invoices to PDF using html2pdf.js

## Technology
HTML, CSS, JavaScript and html2pdf.js

## Run locally
Open `index.html` in a modern web browser.
