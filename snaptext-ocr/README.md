# SnapText

OCR tool for extracting text from screenshots, images and PDFs with crop, rotate and export controls.

## Highlights
- OCR for images, screenshots and PDFs
- Crop, rotate and enhancement controls
- Multilingual text extraction
- TXT/CSV/ZIP export options

## Technology
HTML, CSS, JavaScript, Tesseract.js, PDF.js and JSZip

## Run locally
Open `index.html` in a modern browser.
